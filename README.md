# My Portfolio

A clean and modern personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Modern dark theme with blue accent styling
- Project showcase section
- Services and skills sections
- Contact form and social links
- Smooth animations and carousel effects

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Swiper.js
- Git and GitHub

## Project Structure
- `index.html` – main portfolio page
- `assets/css/styles.css` – styling for the site
- `assets/js/main.js` – main interactivity and animations
- `assets/img/` – project and design assets
